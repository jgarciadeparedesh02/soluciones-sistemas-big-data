## Metodología Didáctica de las Soluciones

Todas las soluciones de este repositorio están redactadas con una **metodología pensada para el aula**:
- **Sin instalaciones complejas:** Nos conectamos directamente a servicios en la nube como MongoDB Atlas mediante clientes de consola (`mongosh`), evitando el uso de contenedores o instalaciones locales pesadas.
- **Formato Markdown explicativo:** Cada concepto técnico se acompaña de explicaciones sencillas, analogías cotidianas y bloques de código listos para copiar, pegar y experimentar en la terminal.
- **Demostraciones causa-efecto:** Se muestran errores provocados para entender las validaciones y comparativas de rendimiento en vivo con herramientas de análisis (`explain`).
